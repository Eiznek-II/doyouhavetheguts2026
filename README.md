# doyouhavetheguts2026
This is a learning tool to understand the Prim-Jarnik algorithm which finds the minimum spanning tree of a graph. We did this project for the GUTS? hackathon in the University of Glasgow, Technology society. The website has a tutorial feature and a game which uses the constellations as a graph and you need to find a the minimum spanning tree from them. 

# Features
The features of this project are:
- Tutorial section explaining the algorithm
- Tutorial section with a visualisation of the algorithm
- Home page where you can chose which constellation
- Interactive game to find the minimum spanning tree
- Zoom into the constellations
- Drag the constellation
- Reset the chosen edges/node
- Check if the minimum spanning tree is correct
